# 説明文の決まり（大田区版）

議案書（区が公開しているPDF）を読んで、区民が一目でわかる説明を書くときの決まり。

## いちばん大事なこと
- **資料に書いてあることだけを書く。** 推測・評価・背景の想像を足さない。「〜と思われる」「〜が期待される」は書かない。
- 金額・日付・施設名・相手先は、資料の数字と名前をそのまま使う（万円単位に丸めるのは可。例：1億8,735万2千円 → 約1億8,735万円）。
- 賛成・反対の良し悪しを書かない。どの会派の立場にも寄らない。

## 書き方
- `headline`：40字前後の一文。「何が・どう決まる（決まった）か」を最初に。正式名称の言い換えではなく中身を書く。
  - 悪い例：「大田区立〇〇条例の一部を改正する条例」
  - よい例：「区立保育園の保育料を、第2子から無料にする」
- `points`：2〜4個の箇条書き。各40字以内。だれに・いくら・いつから・どこで、を優先。
- `amount`：お金が出てくる議案だけ。いちばん大事な金額を1つ（例：「約15億7,850万円」「増額 134万円」）。なければ省く。
- `category`：次のどれか1つ
  子育て・教育 / 福祉・医療 / 防災・安全 / まちづくり・道路 / 環境・ごみ / 産業・観光 / 施設・工事 / 予算・決算 / 人事 / 議会・行政のしくみ
- `areas`：議案に出てくる大田区内の地名（例：蒲田、大森、羽田、池上、馬込、田園調布、糀谷、六郷、矢口、雪谷、千束、久が原、鵜の木、下丸子、東調布、嶺町、平和島、昭和島、京浜島、城南島、東海、入新井、新井宿、山王、大岡山）。施設名に含まれる地名も拾う。なければ空配列。
- 子ども・高齢者・外国にルーツのある人にも読めるよう、漢語を減らし短い文にする。専門用語を使うときは（ ）で短く言い換える。

## 出力形式（JSON）
```json
{
  "kucho-82": {
    "headline": "…",
    "points": ["…", "…"],
    "amount": "約〇億〇万円",
    "category": "予算・決算",
    "areas": []
  }
}
```
キーは `種類-番号`。種類は kucho（区長提出議案）/ giin（議員提出議案）/ iinkai（委員会提出議案）。

## 議案書がないとき（件名だけで書く）
区のサイトから議案書が消えていて、件名しか手に入らない議案もある。そのときは次のようにする。
- `headline` だけを、**件名に書いてあることだけ**でふだんの言葉に言い換える。中身・金額・理由は推測しない。
  - 例：「大田区立〇〇条例の一部を改正する条例」→「区立〇〇のきまりを変える」（何をどう変えるかは書かない）
  - 例：「〇〇工事請負契約について」→「〇〇の工事を会社に頼む契約」
- `points` は空配列 `[]`、`amount` は入れない。
- `"basis": "title"` を必ず入れる（議案書をもとに書いたものは `"basis": "doc"`）。
- `category` と `areas` は件名からわかる範囲で入れる。
